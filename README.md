# Controlo de Férias RH

Sistema web para gestão de funcionários, departamentos, férias, histórico e relatórios.

## Departamentos

- Administração
- Serração
- Vendas
- Carpintaria
- Manutenção
- Mecânica
- Seguranças

## Perfis de acesso

- Administrador: acesso total e gestão de utilizadores/permissões.
- RH: gestão de funcionários, férias, alertas e relatórios.
- Outros utilizadores: acesso conforme permissões definidas pelo Administrador.

## Regras de férias

- Permanente: 30 dias por ano.
- Contratado: 1 dia por mês de contrato.

## Próximas etapas

1. Login e autenticação.
2. Cadastro de funcionários.
3. Departamentos e pesquisa.
4. Gestão de férias e histórico.
5. Alertas e estados de férias.
6. Relatórios.
7. Permissões de utilizadores.
8. Logs/auditoria numa fase posterior.
